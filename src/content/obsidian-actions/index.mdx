# Overview

**Actions** is an [Obsidian](https://obsidian.md/) plugin that lets you define
custom automation using either JavaScript or shell commands. These actions can
be triggered manually, on app startup, on specific file events, or on a schedule.

The plugin is designed to be flexible but safe, exposing a controlled runtime
environment along with contextual variables that can be templated into your scripts.

## Why Actions?

There's two main reasons:

- **Customisation**, lot of the actions I've created already have plugins exist,
the biggest issue I have is that they don't fit my specific use case. This plugin
gives you the flexibility to create exactly what you need.

- **We're lazy**, I could create a full plugin for everything I use plugins for,
that sounds nice but it's way too much effort for a simple bash script.
