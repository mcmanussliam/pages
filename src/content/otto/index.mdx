# Overview

[**Otto**](https://crates.io/crates/otto-cli) simple task runner. Think make, but with built-in retries, timeouts, run history, and notifications.

It supports:

- direct command execution (`exec`)
- shell command execution (`run`)
- task composition (`tasks`)
- retries and timeout control
- run history in `.otto/history.jsonl`
- desktop and webhook notifications

## Why use Otto?

Most task tooling is either too minimal or too heavy. Otto keeps the model small:

- one `otto.yml`
- one command (`otto run ...`) for day-to-day use
- strong defaults with per-task overrides
- predictable exit codes for scripts and agents
