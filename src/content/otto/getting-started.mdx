# Getting Started

## Install

From crates.io:

```bash
cargo install otto-cli --locked
otto version
```

From source:

```bash
git clone https://github.com/mcmanussliam/otto
cd otto
cargo run -- version
```

## First config

Create a starter config:

```bash
otto init
```

You will get `./otto.yml`. Add a quick task:

```yaml
tasks:
  test:
    exec: ["cargo", "test"]
```

Run it:

```bash
otto run test
```

## Useful next commands

- `otto tasks` to inspect what is configured
- `otto validate` to catch config mistakes before running
- `otto history --limit 10` to see recent runs
- `otto completion zsh` (or bash/fish/powershell) for shell completion

## Good defaults for teams

Add this to `defaults` early:

```yaml
defaults:
  timeout: "5m"
  retries: 1
  retry_backoff: "1s"
  notify_on: failure
```
