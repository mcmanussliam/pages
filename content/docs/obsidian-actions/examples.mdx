## Open the Current File in VS Code

Use an absolute path to the `code` executable. Shell aliases are often unavailable in plugin execution contexts.

```bash
/path/to/vs/code/code "{{{path}}}"
```

## Compile LaTeX from a JavaScript Action

```javascript
new Notice('Compiling LaTeX');

const compileScript = '/absolute/path/to/compile-latex.sh';
const filePath = '{{{path}}}';

const parts = filePath.split('/');
const filename = parts.pop();
const directory = parts.join('/');

exec(`cd "${directory}" && "${compileScript}" "./${filename}"`, (err, stdout, stderr) => {
  if (err) {
    console.error(err, stderr);
    new Notice('Compilation failed');
    return;
  }

  console.log(stdout);
  new Notice('Compilation succeeded');
});
```

## Supporting Shell Script for the LaTeX Example

```bash
set -e

if [ -z "$1" ]; then
  echo "Usage: $0 /full/path/to/file.tex"
  exit 1
fi

filepath="$1"
directory="$(dirname "$filepath")"
filename="$(basename "$filepath")"
basename_no_ext="${filename%.*}"

export PATH="/path/to/tiny/tex"

cd "$directory"

pdflatex --shell-escape -interaction=nonstopmode "$filename"
bibtex "$basename_no_ext" || true
pdflatex --shell-escape -interaction=nonstopmode "$filename"
pdflatex --shell-escape -interaction=nonstopmode "$filename"
```

## When to Use These Patterns

- Use a shell action if the workflow already exists as a script.
- Use a JavaScript action if you want Obsidian UI feedback such as `Notice` messages or need to combine app context with shell execution.
