description: Claude MCP server that adds fine-grained, per-project and per-operation access control for GitLab CE tokens.
---

GitLab CE has no fine-grained access tokens; your token either has api scope or it doesn't. This Claude plugin enforces
per-project, per-operation restrictions that your GitLab instance can't.

## How It Works

1. Install the plugin.
2. Create a token and add it to your os keychain.
3. Set-up the config.
4. And use glab safely without worry of Claude deleting everything.
